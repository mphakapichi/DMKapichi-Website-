## 🎨 Customization Guide for Premium Edition

### Change Cyan Color to Your Brand
Search and replace `#00d4ff` with your color:

**All instances to change:**
- Navigation underline
- Buttons
- Card borders on hover
- Text accents
- Social link backgrounds
- Form focus states

**Example**: Change to blue
```css
/* Find: #00d4ff */
/* Replace with: #2563eb */
```

### Change Video Background
```html
<!-- Find this line in index-premium.html: -->
<source src="https://videos.pexels.com/video-files/3130279/3130279-hd_1920_1080_25fps.mp4" type="video/mp4">

<!-- Replace with your video URL: -->
<source src="your-video-url.mp4" type="video/mp4">
```

**Video Suggestions:**
- Cybersecurity/code-related videos
- Network/infrastructure videos
- Tech-related stock footage
- Custom company videos

### Change Overlay Darkness
```css
/* Find this in style-premium.css: */
.video-overlay {
    background: linear-gradient(135deg, rgba(0, 0, 0, 0.7), rgba(0, 0, 0, 0.5), rgba(0, 0, 0, 0.7));
}

/* Adjust the 0.7 and 0.5 values:
   - Higher = darker overlay
   - Lower = lighter overlay
   - Try: 0.8, 0.6 for darker
   - Try: 0.5, 0.3 for lighter */
```

### Add Client Logos
Replace placeholder text with actual images:
```html
<!-- Change from: -->
<div class="client-placeholder">Computer Automation Ltd</div>

<!-- To: -->
<img src="path/to/logo.png" alt="Company Name">
```

## 🎬 Video Background Best Practices

### File Size Optimization
- Use WebM or MP4 format
- Compress to 5-15MB for best performance
- Use 1920x1080 resolution
- Duration: 15-30 seconds (loops)

### Video Content Ideas
1. **Code compilation/execution**
2. **Hacking/security themes**
3. **Network visualizations**
4. **Data flowing**
5. **Terminal screens**
